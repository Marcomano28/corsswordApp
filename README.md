# Crossword App

A modern crossword puzzle application built with React, Vite, and styled-components.

## Features

- Interactive crossword puzzle interface
- Real-time validation
- Responsive design
- Word matching functionality

## Getting Started

To run this project locally:

1. Clone the repository
2. Install dependencies with `npm install`
3. Start the development server with `npm run dev`

## Technologies Used

- React
- Vite
- Styled Components
- JavaScript
